# wiki-plugin-fish-picker

The site identity flag editor: a parametric Mice & Fish favicon picker that writes status/favicon.png (owner only). Loaded farm-wide by the hitchhiker security bootstrap.

Extracted from wiki-plugin-hitchhiker's `wiki-ux.js` in August 2026 — see the About page in `pages/` and `Loading the UX Layer` on plugin.fedwiki.club. Source in `src/`, built with esbuild to `client/` (`npm run build`).
